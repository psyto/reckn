# Tokyo speaker card — plain English

**Pre-event script aid only.** The words below are a reading aid for the video and live judging.
They do not replace the evidence, and they make no claim beyond `DEMO.md` and `VIDEO-RUNBOOK.md`.

## How to use this card

- A `/` is a short pause. Do not say it aloud.
- **Bold** is the word to stress.
- If a line feels hard to say, stop after the slash. Do not speak faster to fit it.
- The screen must already show the state before the spoken line explains it.

## Video opener — first minute

> I want a world / where we can pay for **work** / without first deciding / who to trust.

> This is an AI agent’s report card. / The owner tries a perfect score. / The contract stops it.

> A second wallet / sends the same score. / It works.

> The check asks only / if I am the owner. / I used another address. / It never asks / whether work happened.

> So we made a record / the agent cannot write. / The same agent tries. / It is refused.

> This is ENS access control. / This agent has no right to write.

> Who gets that right? / The buyer — / but only after settlement.

> A program reruns the job / and gets the same result. / No one can choose otherwise. / There is no key for that.

> Settlement gives the buyer / one right to write. / Then it disappears.

## Uniswap and the close

> The job is a real Uniswap swap. / We rerun the full swap / and check the result. / A program checks it, / not a person.

> Earning happens on v3. / Spending happens on v4. / No record, / no swap.

> Now the record is written. / Same swap. / The record is the pass.

> Clear the record, / and the pool closes again.

> Banks settle in batches, / so someone reconciles later. / On chain, / each transaction settles now.

> Nothing to reconcile. / Nothing to undo. / Each decision must be right / the first time.

> We use re-execution, / not a person with permission.

## Limits — say them plainly

> This does not solve identity. / An agent can pay itself.

> The buyer chooses the verifier. / A weak verifier / gives a weak settlement.

> The gate is for trading, / not liquidity.

## Live judging spine — about 90 seconds

Use the opener through “Then it disappears.” Then show the three v4 states without adding
architecture detail:

> No record, no swap. / Now the record is written. / Same swap. / The record is the pass. /
> Clear the record, / and it closes again.

Then stop. Let the panel choose the next question.

## Answers to likely interruptions

| question | short answer |
|---|---|
| Who uses this? | “Nobody yet. I will not pretend otherwise. This is a mechanism, and these are the measurements behind it.” |
| Can the agent pay itself? | “Yes. We do not solve identity. We close the narrower path: no settlement, no record.” |
| Is this mainnet? | “This event demo is on Sepolia testnet.” |
| Why v3 and v4? | “v3 is the work we rerun. v4 is where the earned record is used. Earning and spending are different acts.” |
| Why not use a human reviewer? | “A human can decide. Our point is that this decision is re-executed instead.” |

## Do not improvise these claims

- “Unforgeable”
- “No path skips proof verification”
- “It protects liquidity”
- “It ran on mainnet”
- “ERC-8004 is broken”
