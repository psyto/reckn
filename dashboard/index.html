Every value on the Reckn side is real output of the reexec-evm engine (revm 38), run against a Merkle-Patricia-proof-verified pre-state bound to the committed state_root — no trusted RPC, no implicit defaults.

Regenerate: cargo run --example moneyshot. The trace_hash is the SHA-256 of the canonical ReplayRecordV1 — anyone can replay the same inputs and reach the same verdict. The opinion judge is a stand-in: it approves on the persuasive claim regardless of what actually executed.

Settlement is authorized by a registered resolver signature; reproducibility and settlement authority are deliberately separate. A trace hash alone is not trustless settlement.
